Знайомство з Git
Git допомагає відстежувати зміни в коді. Обери вкладку, щоб переглянути приклади основних команд.
Перевірка змінГілки ІсторіяНадсилання

Terminal — git
$ git status
Перевірити стан робочої директорії
Побачити змінені та нові файли
$ git branch
Переглянути наявні гілки

$ git switch -c feature
Створити та перейти в нову гілку
$ git log --oneline
Переглянути історію комітів у скороченому вигляді
$ git add .
$ git commit -m "Add initial website"
$ git push
Зберегти зміни та надіслати їх на GitHub
